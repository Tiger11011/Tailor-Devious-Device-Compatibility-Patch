[b]Description[/b]
This compatibility patch fixes equipment-changing issues between Devious Devices (DD) and Tailor - An Outfit and Wig Manager, allowing supported DD restraint gear to be tried on and changed in Tailor. For full details and supported versions, please refer to the [url=https://github.com/Tiger11011/Tailor-Devious-Device-Compatibility-Patch]GitHub repository[/url].

[b]Installation instructions[/b]
Install the FOMOD with MO2 and choose 中文 or English. Install Tailor and any translation separately.
For a first installation, use the included Tools/build_cosmetics.py to generate equipment data for your own MO2 profile. Install the generated ZIP as a separate mod and enable TailorDDCosmetics.esp. Follow the [url=https://github.com/Tiger11011/Tailor-Devious-Device-Compatibility-Patch/blob/main/README.md]README instructions[/url]. Keep existing matching Generated Data when updating the patch.

[b]How to use[/b]
Open Tailor in game (Shift + Z by default) → Settings → DD Settings.
Choose the mode, confirm the outfit using Tailor's Set workflow, then exit normally. Adding or previewing an item alone does not confirm an outfit.

[b]Main features[/b]
• Off (default): after confirming and exiting Tailor, supported patch-managed DD clothing can be changed through Tailor and the normal inventory, while genuine DD sounds, animations and other effects remain.
• On: normal DD clothing restrictions remain after confirming and exiting Tailor.
• While fitting, supported devices use removable appearance copies. This is not a global unlock tool: quest devices, devices that block generic removal, unsupported custom scripts and independently locked existing devices are not forcibly unlocked.
• Tailor itself shares NPC outfit assignments across saves. This patch retains that behavior; it does not mean DD lock state is necessarily identical in every save. The patch's free-wear permissions are stored in its own SKSE co-save data, so retain each save's matching co-save.

[b]Requirements[/b]
• PapyrusUtil SE, matching your game/SKSE.
• Tailor 3.0.1: an exact supported English or CHS build.
• Devious Devices, its equipment dependencies, and the exact reviewed Devious Devices NG v0.4.3 rc2 DLL.
• Skyrim SE/AE with matching SKSE64, Address Library and the Microsoft Visual C++ x64 runtime required by the native plugins.
• MO2 and Python 3.10+ for equipment-data generation; Python is only needed for generation.
• Optional: the reviewed Mu Dynamic NPC Replacer 2.1.4 and its RaceMenu requirement for Mu appearance recovery. Tailor's supported Chinese translation is obtained separately if needed.
Check the README's DLL hashes; version names alone are not enough. Local testing used Skyrim 1.6.1170. Other game runtimes and VR have not been validated.

[b]AI usage[/b]
I used generative AI for vibe coding. No art assets were generated using AI.

[b]Feedback and bug report[/b]

Please report either on Nexus or the [url=https://github.com/Tiger11011/Tailor-Devious-Device-Compatibility-Patch]GitHub repository[/url].

Include [b]TailorDDBridge.log[/b] and [b]Tailor.log[/b], normally located in Documents\My Games\Skyrim Special Edition\SKSE\. If your Documents folder has been moved or redirected to OneDrive, use its actual location. The patch log is still named TailorDDBridge.log despite the mod's new name.

If the bug concerns character appearance (e.g. skin colour or face sculpt), rather than only equipment, please also include the following logs for the mods you use:

• [b]RaceMenu:[/b] Documents\My Games\Skyrim Special Edition\SKSE\skee64.log.
• [b]Mu Dynamic NPC Replacer:[/b] <Skyrim game folder>\Data\SKSE\Plugins\MuDynamicNPCReplacer.log. With MO2, the physical file may be in the Mu mod's SKSE\Plugins\ folder or in Overwrite\SKSE\Plugins\ (or a configured output mod).

[b]Copy the logs immediately after reproducing the issue, before restarting the game. Each game launch overwrites TailorDDBridge.log.[/b] Attach complete log files, rather than only their last lines.

Please provide:

• Patch, Skyrim, SKSE, Tailor, DD and DD NG versions; patch language and any Tailor translation used.
• Whether the affected character is the player or an NPC, and the NPC's name if applicable.
• Whether DD Settings was Off or On, and the exact steps to reproduce, including previewing, confirming with Set and exiting Tailor.
• Equipment names and their source mods; expected behavior and what actually happened.
• For appearance issues, whether Mu/RaceMenu is used and their versions.

Review logs for personal information, such as Windows usernames in file paths, before posting publicly.
