[b]简介[/b]
这是一个兼容性补丁模组，用于修复 Devious Devices（DD）与 Tailor - An Outfit and Wig Manager 之间的换装问题，让受支持的 DD 拘束装备可以在 Tailor 试衣间里试穿和更换。详细信息及受支持版本请以 [url=https://github.com/Tiger11011/Tailor-Devious-Device-Compatibility-Patch]GitHub 仓库[/url]为准。

[b]安装说明[/b]
用 MO2 安装 FOMOD，选择“中文”或“English”。Tailor 和汉化需自行安装。
首次安装还需使用包内 Tools/build_cosmetics.py，为自己的 MO2 配置生成装备数据；将生成的 ZIP 作为独立模组安装，并启用 TailorDDCosmetics.esp。具体步骤见[url=https://github.com/Tiger11011/Tailor-Devious-Device-Compatibility-Patch/blob/main/README.zh-CN.md]中文 README[/url]。更新补丁时保留现有匹配的 Generated Data。

[b]怎么用[/b]
游戏内打开 Tailor（默认 Shift + Z）→ 设置 → DD 设置。
选择模式，通过 Tailor 的 Set 流程确认套装，再正常退出。仅添加或预览装备不等于确认套装。

[b]主要功能[/b]
• 关闭（默认）：确认并退出 Tailor 后，补丁管理的受支持 DD 衣服可以在 Tailor 和普通物品栏自由穿脱，保留真实 DD 的音效、动画等原有效果。
• 开启：确认并退出 Tailor 后保留 DD 正常穿脱限制。
• 试衣期间，受支持设备使用可自由穿脱的外观副本。本补丁不是全局解锁工具，不强制解除任务设备、阻止通用卸装的设备、未知自定义脚本或其他玩法独立锁上的既有设备。
• Tailor 本身会跨存档共享 NPC 套装分配，本补丁保留该行为；这不代表每个存档里的 DD 锁定状态必然相同。补丁的自由穿脱权限另存于 SKSE 配套存档记录，请保留各存档对应的 co-save。

[b]前置[/b]
• 与游戏/SKSE 匹配的 PapyrusUtil SE。
• Tailor 3.0.1，须为已支持的英文或汉化构建。
• Devious Devices、服装本身的前置，以及已核查的 Devious Devices NG v0.4.3 rc2 DLL。
• Skyrim SE/AE、匹配的 SKSE64、Address Library 及原生插件需要的 Microsoft Visual C++ x64 运行库。
• MO2、Python 3.10 或更高版本；Python 仅在生成装备数据时需要。
• 可选：已核查的 Mu Dynamic NPC Replacer 2.1.4 及其 RaceMenu 前置，用于 Mu 外观恢复。需要 Tailor 汉化时请自行下载受支持版本。
请核对 README 中的 DLL 哈希，不能仅凭版本名称判断兼容。实测使用 Skyrim 1.6.1170，其他游戏版本及 VR 未验证。

[b]问题反馈[/b]
日志通常位于“文档\My Games\Skyrim Special Edition\SKSE\”。如果“文档”已迁移或重定向到 OneDrive，请使用实际位置。
[b]复现后，请在重启游戏前复制 TailorDDBridge.log；每次启动游戏都会覆盖该日志。[/b] 如有同目录的 Tailor.log，也请一并提供。
请附补丁/游戏/SKSE/Tailor/DD/DD NG 版本、补丁语言及是否使用 Tailor 汉化、玩家或 NPC（及 NPC 名称）、开关状态、装备名称及所属模组、完整复现步骤、预期表现和实际问题。外观问题另附 Mu/RaceMenu 版本及已生成的相关日志。公开前请检查日志中的个人信息。
